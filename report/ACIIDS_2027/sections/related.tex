\section{Related Work}
\textbf{Group-robust training.}
Group DRO minimises the worst-group loss and shows that strong regularisation is needed for it to generalise \cite{sagawa2020groupdro}. Methods that need no group labels at training time include Just Train Twice, which upweights the examples a first model gets wrong \cite{liu2021jtt}, Learning from Failure \cite{nam2020lff} and Correct-N-Contrast \cite{zhang2022cnc}. Simple balancing of classes or groups is competitive \cite{idrissi2022balancing}. SubpopBench compares such methods under a common protocol and finds that no method wins everywhere \cite{yang2023subpopbench}; the same lesson motivates our attention to how validation data are spent. \TODO{check this summary of SubpopBench against its abstract} These methods change how the backbone is trained, whereas the methods we study keep the backbone frozen.

\medskip\noindent\textbf{Last-layer retraining.}
Deep Feature Reweighting (DFR) retrains the last layer on a group-balanced held-out set and recovers most of the WGA that full-network group methods reach \cite{kirichenko2023dfr}. It builds on the observation that spurious correlations leave the learned features useful and mostly harm the final layer \cite{izmailov2022feature}; later work reduces the annotations needed \cite{labonte2023fewer,qiu2023afr}. DPE sits in the same family: a frozen backbone, a small annotated validation set and a light head. We therefore declare a DFR-style control on the same features and labels: group-balanced L1-penalised logistic regression with the penalty chosen by cross-validation on validation data. It is a different head trained under the same supervision, not an unannotated baseline. \TODO{the DPE paper lists a DFR number for Waterbirds; check the exact value and setting before quoting it}

\medskip\noindent\textbf{Prototype ensembles.}
DPE \cite{to2025dpe} trains 15 prototype heads in sequence on the frozen features. Each head is a distance-based prototype classifier, is trained on a group-balanced subset of the annotated validation set, and is pushed away from earlier heads by a covariance penalty; the class probabilities of the heads are averaged uniformly. Averaging members is the default way to use an ensemble \cite{lakshminarayanan2017deepensembles}. \medskip\noindent\textbf{Stacking and cross-fitting.}
Stacked generalisation fits a second-level model on out-of-sample predictions of first-level models \cite{wolpert1992stacking,breiman1996stacked}. Cross-fitting, which produces each nuisance prediction from a model that did not see that example, is standard in double machine learning \cite{chernozhukov2018dml}. Our procedure applies this idea to the validation-budget constraint of DPE: the calibrator sees only out-of-fold scores, and every image is used both to train heads (in four of five folds) and to calibrate (in one). The idea is not new; its value here is an empirical question.

\medskip\noindent\textbf{Calibration and threshold adjustment.}
Platt scaling fits a logistic map of a classifier score \cite{platt1999probabilistic}, and temperature scaling is its one-parameter form for neural networks \cite{guo2017calibration}. Logit adjustment and cost-sensitive thresholds shift the decision boundary to match a target loss or prior \cite{elkan2001cost,menon2021logit}. For one binary score, positive scaling does not change the ranking, so recalibration changes decisions only through the threshold. In the cross-fitted ensemble the calibrated probabilities of five different ensembles are averaged, so the scale parameter can matter there; threshold-only controls measure how much it does.

\medskip\noindent\textbf{Reliability of evaluation.}
Differences between methods on Waterbirds are often a few tenths of a point and depend on the validation partition, the seed and the model-selection rule \cite{yang2023subpopbench}. We report fold-split noise, state which choices were made on validation data and which after test results had been seen, and audit the dataset labels.
