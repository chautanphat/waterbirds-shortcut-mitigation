\begin{abstract}
Group-robust methods on Waterbirds rely on a small validation set with group labels that must both fit a light head on frozen features and, in recent work, learn how to combine ensemble members. We ask how that budget should be spent for diverse prototypical ensembles (DPE). On seven saved ResNet-50 backbones (five standard ERM, two ERM$^*$), we compare combiners that reserve 479 validation images with DPE fitted on all 1,199. We then study cross-fitting: five ensembles trained on four fifths of the images each, an affine recalibration fitted on their out-of-fold scores, and test scores averaged over the five. Because an affine map of one binary score is a threshold shift, we pair it with threshold-only controls on the same ensembles and with DFR-style retraining on the same features and labels. \framing{} The study covers one dataset, and the test set was inspected during earlier development, so all results are exploratory.
\keywords{Subpopulation shift \and Worst-group accuracy \and Prototype ensembles \and Cross-fitting \and Calibration \and Waterbirds}
\end{abstract}
