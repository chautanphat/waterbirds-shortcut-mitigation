# Known limitations

- `arubique/waterbirds` supplies official test images only. It cannot supply an independent training/validation experiment. Model/checkpoint selection is fixed; all test inspection is retrospective exploratory.
- Dataset/background categories do not prove what cues a model uses. Synthetic interventions and a single bird cannot establish a general causal shortcut-amplification claim. Multiple birds/backgrounds/seeds and predeclared evaluation are needed for aggregate conclusions.
- Exact invariance applies to the saved foreground layer, fixed geometry and opaque composite pixels. Fractional-alpha boundary RGB varies with background. The logged initial resample and crop can remove some source evidence; exact model views are exported.
- Gray-matte JPEG extraction and manual mask correction are explicitly approximate. They require opt-in and cannot support verified original-foreground claims. Original CUB download or a local original RGB/mask root enables verified cutouts. Missing masks or invalid/full-frame masks fail loudly.
- No human/animal content detector or learned near-duplicate detector is installed. Exact duplicates are screened; average-hash collisions are candidates for manual inspection. Background reuse is recorded; bird-cluster CIs do not estimate generalization to a new background distribution.
- No compatible, historically hash-bound original-DPE checkpoint exists in this working checkout. The Lab's optional DPE adapter retains its strict exporter contract. The separate `scripts/investigate_poter_failure.py` explicitly evaluates the sibling checkout's legacy `kaggle_exploration/seed0/ensemble.pt` with its co-located saved enhanced-ERM backbone: both current file hashes are frozen, all 1,199 head-training IDs are canonical validation, and prediction parity with the original ensemble code is checked. Historical head/backbone hash binding remains absent and the association is disclosed as exploratory. See `results/poter_failure/checkpoint_audit.json`; do not interpret it as a fully matched benchmark. The Lab does not silently accept this legacy format.
- Imported legacy prediction CSVs are validated standalone artifacts. They are not shown as native paired runs when exact source/model-view assets or counterfactual pairing are absent. No probabilities, saliency or missing images are fabricated.
- Re-run/resume preserves earlier runs and creates a new run from the saved configuration; it does not continue half a GPU batch in place. Only completed runs have final aggregate summaries. Interactive runs are capped at 1,000 birds and 100 backgrounds per category; partition larger studies using saved configs.
- Independent seed-level dispersion is undefined for one supplied checkpoint. Bootstrap CIs require at least two source birds. WGA is undefined unless all four label/background groups are present. DPE paired score margins use log averaged probabilities and must not be compared numerically as POTER native logits.
- PNG previews retain exact pixels; PDF/montage displays rescale for layout. PNG sources, row IDs, hashes and complete CSVs remain authoritative. App launch is localhost-only; no authentication or public hosting is configured.
- Five existing DPE ERM-star orchestration tests require Linux: four mock `os.killpg`, which does not exist on Windows, and the notebook execution fixture inserts unescaped Windows paths into Unix notebook literals. They are reported separately from the Windows-applicable suite; no baseline method implementation was changed to hide these platform constraints. Run the complete orchestration suite on Linux/Kaggle. Use UTF-8 mode on Windows for notebook fixtures.
